# rusty-key-bot

Telegram-бот менеджера паролей на Rust.

## Технологии

- `teloxide` + `tokio`
- `sqlx` + SQLite
- `argon2` для проверки мастер-пароля
- `chacha20poly1305` (AEAD) для шифрования секретов
- `tracing` + `tracing-subscriber`
- `thiserror` + `anyhow`

## Команды

- `/start` - приветствие и ограничения
- `/help` - список команд
- `/set_master [master]` - установить/сменить мастер-пароль
- `/add [service login password note?]` - добавить запись (или пошагово)
- `/get <service>` - получить запись по сервису (с вводом мастер-пароля)
- `/list` - список сервисов
- `/delete <service>` - удалить запись
- `/gen [len] [special:true|false]` - генератор паролей

## Запуск

1. Создать `.env` (или экспортировать переменные):
   - `BOT_TOKEN=<telegram bot token>`
   - `DATABASE_URL=sqlite://rusty_key.db` (опционально)
2. Запустить:

```bash
cargo run
```

## Модель угроз (MVP)

- Данные в БД хранятся только в зашифрованном виде.
- Мастер-пароль в БД не хранится в открытом виде, только Argon2 hash.
- Если Telegram-аккаунт пользователя скомпрометирован, злоумышленник может получить доступ к боту и данным.
- Сообщения с мастер-паролем бот пытается удалять после обработки (`best effort`), но это не абсолютная гарантия.
- Recovery механизма при утере мастер-пароля в MVP нет.
